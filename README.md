# autocad-knowledge

Tri thức đọc và làm việc với bản vẽ AutoCAD (DWG xuất từ Revit) dùng cùng [AutoCAD MCP Launcher](https://github.com/KenjiIT/autocad-mcp-launcher). Các trang nằm trong `wiki/`; bắt đầu từ [`wiki/index.md`](wiki/index.md).

Đây là bản công khai, đã bỏ tên và số liệu của dự án cụ thể. Tải về bằng "Download ZIP" hoặc `git clone`. Nội dung là kinh nghiệm tham khảo; hãy kiểm tra lại trên bản vẽ của bạn trước khi dựa vào.
